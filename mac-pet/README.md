# Мурка — настольный питомец для macOS

Рыжий котёнок, который живёт у тебя на экране над Dock.

- гуляет по экрану, прыгает, засыпает (с «zzz»);
- запрыгивает на верхние края открытых окон и гуляет по ним; если окно подвинуть — едет вместе с ним, если закрыть — падает;
- забирается по боковым краям экрана, ходит вверх ногами под строкой меню и спрыгивает вниз;
- следит глазами за курсором;
- клик — погладить (сердечки и мурчание), перетаскивание — взять на руки, отпустишь — упадёт на лапы;
- со временем проголодается и попросит есть;
- меню — в строке меню (🐱) или правым кликом по котёнку: покормить, позвать к курсору, ходить за курсором, лазать по окнам и стенам (можно выключить), уложить спать, автозапуск при входе, выход.

## Установка

Нужны Xcode Command Line Tools (один раз):

```bash
xcode-select --install
```

Сборка и запуск:

```bash
cd mac-pet
./build.sh
open build/Murka.app
```

Чтобы Мурка была всегда под рукой — перетащи `build/Murka.app` в «Программы» и включи в её меню «Запускать при входе в систему».

Работает на macOS 12+ (автозапуск — с macOS 13), на Intel и Apple Silicon.
